## Задание 1. Атрибут класса: счётчик объектов

Напишите класс `Book`, который считает, сколько всего объектов было создано.

**Требования:**
- Атрибут класса `total_books`, который увеличивается на 1 при создании каждого нового объекта
- Атрибуты экземпляра: `title`, `author`
- Метод `__str__`, возвращающий строку вида `"Title — Author"`

**Проверка:**
```python
b1 = Book("Мастер и Маргарита", "Булгаков")
b2 = Book("1984", "Оруэлл")
print(Book.total_books)   # 2
print(b1)                 # Мастер и Маргарита — Булгаков
```

## Задание 2. classmethod и staticmethod

Дополните класс `Book` из задания 1:

**Требования:**
- `classmethod` с именем `from_string`, который принимает строку вида `"Title, Author"` и создаёт объект `Book` (альтернативный конструктор)
- `staticmethod` с именем `is_valid_title`, который проверяет, что название книги не пустое и не состоит только из пробелов

**Проверка:**
```python
b3 = Book.from_string("Гарри Поттер, Роулинг")
print(b3)                              # Гарри Поттер — Роулинг

print(Book.is_valid_title("   "))      # False
print(Book.is_valid_title("Дюна"))     # True
```

## Задание 3. Инкапсуляция

Напишите класс `BankAccount`.

**Требования:**
- Атрибут `owner` — публичный
- Атрибут `__balance` — приватный (с name mangling), при создании объекта задаётся стартовым балансом
- Метод `deposit(amount)` — пополнение счёта (сумма должна быть положительной, иначе `raise ValueError`)
- Метод `withdraw(amount)` — снятие средств (нельзя снять больше, чем есть на счёте — тоже `ValueError`)

**Проверка:**
```python
acc = BankAccount("Иван", 1000)
acc.deposit(500)
acc.withdraw(200)
print(acc._BankAccount__balance)   # 1300

acc.withdraw(999999)               # должно вызвать ValueError
```

## Задание 4. @property

Перепишите `BankAccount` из задания 3 так, чтобы баланс был доступен через `@property` под именем `balance` — **только для чтения** (без setter'а, попытка `acc.balance = 100` должна вызывать ошибку).

**Проверка:**
```python
acc = BankAccount("Иван", 1000)
print(acc.balance)     # 1000
acc.balance = 5000      # AttributeError: can't set attribute
```

## Задание 5 (со звёздочкой). Собираем всё вместе

Напишите класс `Product` для интернет-магазина:

**Требования:**
- Атрибуты экземпляра: `name`, `_price` (приватный по соглашению)
- `@property price` — геттер, возвращающий цену
- `@price.setter` — сеттер, который не позволяет установить отрицательную цену (`raise ValueError`)
- Атрибут класса `currency = "RUB"`, общий для всех товаров
- `classmethod` `from_dict(cls, data)`, создающий объект `Product` из словаря вида `{"name": ..., "price": ...}`
- `__str__`, возвращающий строку вида `"Название: 999 RUB"`

**Проверка:**
```python
p1 = Product.from_dict({"name": "Клавиатура", "price": 2500})
print(p1)                  # Клавиатура: 2500 RUB

p1.price = -100             # должно вызвать ValueError

Product.currency = "USD"
print(p1)                  # Клавиатура: 2500 USD  (атрибут класса общий!)
```
