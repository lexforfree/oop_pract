## Задание 1. __str__ и __repr__

Напишите класс `Fraction` (дробь) с полями `numerator` (числитель) и `denominator` (знаменатель).

**Требования:**
- `__str__` — возвращает дробь в виде `"1/2"`
- `__repr__` — возвращает `"Fraction(numerator=1, denominator=2)"`

**Проверка:**
```python
f = Fraction(1, 2)
print(f)         # 1/2
print(repr(f))   # Fraction(numerator=1, denominator=2)
```

## Задание 2. Сравнения

Дополните класс `Fraction` из задания 1 так, чтобы дроби можно было сравнивать между собой **по значению**, а не по числителю/знаменателю напрямую (`1/2` должно быть равно `2/4`).

**Требования:**
- `__eq__`
- `__lt__`
- Используйте `@total_ordering` из `functools`, чтобы не писать все операторы вручную

**Проверка:**
```python
a = Fraction(1, 2)
b = Fraction(2, 4)
c = Fraction(1, 3)

print(a == b)   # True  (1/2 == 2/4)
print(a > c)    # True  (1/2 > 1/3)
print(a <= b)   # True
```

## Задание 3. Арифметика

Дополните класс `Fraction` арифметикой.

**Требования:**
- `__add__` — сложение дробей (a/b + c/d = (a*d + c*b) / (b*d))
- `__mul__` — умножение дробей (a/b * c/d = (a*c) / (b*d))
- Результат — тоже объект `Fraction` (можно не сокращать дробь, это необязательно)

**Проверка:**
```python
a = Fraction(1, 2)
b = Fraction(1, 3)
print(a + b)   # 5/6
print(a * b)   # 1/6
```

## Задание 4. Работаем как список

Напишите класс `Matrix` — простую обёртку над списком списков (матрицей чисел).

**Требования:**
- `__init__(self, rows)` — принимает список списков, например `[[1, 2], [3, 4]]`
- `__len__` — количество строк
- `__getitem__(self, index)` — возвращает строку матрицы по индексу
- `__contains__(self, value)` — проверяет, есть ли значение хотя бы в одной строке

**Проверка:**
```python
m = Matrix([[1, 2], [3, 4]])
print(len(m))        # 2
print(m[0])           # [1, 2]
print(3 in m)          # True
print(9 in m)          # False
```

## Задание 5. Свой итератор

Напишите класс `Fibonacci`, который через итерацию выдаёт первые N чисел Фибоначчи.

**Требования:**
- `__init__(self, n)` — сколько чисел нужно выдать
- `__iter__` и `__next__` — по протоколу итератора
- Не забудьте поднять `StopIteration`, когда числа закончились

**Проверка:**
```python
for num in Fibonacci(7):
    print(num, end=" ")
# 0 1 1 2 3 5 8
```

## Задание 6 (со звёздочкой). __call__ и контекстный менеджер

Напишите класс `Discount`, который ведёт себя одновременно как вызываемый объект и как контекстный менеджер.

**Требования:**
- `__init__(self, percent)` — процент скидки
- `__call__(self, price)` — возвращает цену с применённой скидкой
- `__enter__` — печатает `"Скидка активирована"` и возвращает self
- `__exit__` — печатает `"Скидка закончилась"`

**Проверка:**
```python
with Discount(20) as d:
    print(d(1000))   # 800.0
# Скидка активирована
# 800.0
# Скидка закончилась
```
